# 🎓 UnicTracker — Liquid Glass Edition (iOS 26 / 27)

> **UnicTracker** — нативное, легковесное и быстрое приложение для iPhone с ультрасовременным интерфейсом **Liquid Glass** (динамические преломления, эффект жидкого стекла, спекулярные блики и неоновые градиенты) для отслеживания учебы, лабораторных, практик, домашних заданий и сессии в университете.

---

## ✨ Основные возможности

1. **Дизайн Liquid Glass (iOS 26/27)**:
   - Многослойное матовое и рефрактивное стекло (`.ultraThinMaterial`, спекулярные грани, динамические неоновые подложки).
   - Поддержка тем оформления: *Cyber Glass, Obsidian OLED, Aurora Glass, Nebula Purple, Emerald Glass, Sapphire*.
   - Плавная физика пружин (`.spring`), тактильный отклик (Haptic Feedback) на каждое действие.
   - Плавающая нижняя панель навигации (Floating Liquid Pod TabBar).

2. **Главный дашборд и трекер заданий**:
   - Круговой жидкостный индикатор общего прогресса семестра.
   - Счетчики по приоритетам: **Критичные**, **Высокие**, **Средние**, **Низкие**.
   - Живой таймер обратного отсчета до сессии / окончания семестра.
   - Фильтрация по предметам в 1 тап (карусель чипов) и быстрый поиск по названию/описанию.
   - Вложенные подзадачи (чеклисты) и быстрый чекбокс выполнения.

3. **Режим «Сессия и Экзамены»**:
   - Экзамены: выставление оценок (5, 4, 3, 2 / пересдача) и трекер готовности экзаменационных билетов.
   - Зачеты / Диф. зачеты / Курсовые: отметка «Зачтено / Не зачтено».
   - Статус допуска к сессии по каждому предмету («Допуск получен / Нет допуска»).
   - Расчет среднего балла (GPA) за сессию в реальном времени.

4. **Визуальный Конструктор и Редактор**:
   - По умолчанию приложение чистое — вы сами создаете свои семестры, курсы и дисциплины.
   - **Пакетный генератор заданий в 1 клик**: мгновенное создание пачки лабораторных (например, сразу создать 8 лабораторных с шаблоном отчета и защиты).
   - Настройка цвета дисциплины, иконки SF Symbols, ФИО преподавателя, аудитории/ссылки.

5. **Архивация семестров**:
   - Кнопка «Завершить семестр и архивировать» фиксирует все оценки, статистику сдачи и личные заметки в локальный архив.
   - Автоматически открывает чистый следующий семестр (например, 2 семестр или следующий курс).

6. **Полная автономность и Центр Настроек**:
   - 100% хранение данных локально на iPhone (без сторонних серверов).
   - **Экспорт в JSON**: сохранение бэкапа в Файлы, отправка в Telegram / AirDrop.
   - **Импорт из JSON**: восстановление из резервной копии с предварительной валидацией и предпросмотром.
   - Кнопка быстрой загрузки демо-данных и сброса базы.

## 🚀 Как собрать IPA без Mac через GitHub Actions и подписать в GBox

Так как у вас нет Mac, сборка происходит в облаке GitHub на серверах macOS абсолютно бесплатно!

### Шаг 1. Откройте репозиторий на GitHub

Код уже загружен в репозиторий: **[https://github.com/l1ratch/UnicTracker](https://github.com/l1ratch/UnicTracker)**

---

### Шаг 2. Автоматическая сборка Unsigned IPA

1. Перейдите в ваш репозиторий во вкладку **[Actions](https://github.com/l1ratch/UnicTracker/actions)**.
2. Workflow `Build Unsigned IPA` запускается автоматически при каждом коммите/пуше (или нажмите кнопку **Run workflow** вручную).
3. Через ~1.5–2 минуты сборка завершится зеленой галочкой.
4. Откройте завершенный запуск и в разделе **Artifacts** скачайте архив `UnicTracker-unsigned-ipa`.
5. Внутри будет готовый файл **`UnicTracker-unsigned.ipa`**.

---

### Шаг 3. Подпись и установка через GBox

1. Передайте скачанный файл `UnicTracker-unsigned.ipa` на ваш iPhone (через Telegram / AirDrop / iCloud Drive).
2. Откройте приложение **GBox** (или Scarlet / TrollStore / AltStore / ESign) на iPhone.
3. Перейдите во вкладку файлов / импорта и выберите `UnicTracker-unsigned.ipa`.
4. Нажмите **Подписать (Sign)**, выберите ваш личный сертификат разработчика.
5. Нажмите **Установить (Install)**.
6. Готово! Приложение появится на главном экране iPhone со всеми иконками, Liquid Glass интерфейсом и локальным хранилищем.
